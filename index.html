        Generar jugadas

        Cada jugada cumple filtros tomados del historial: suma dentro del rango donde cae el 80% de los sorteos, entre 2 y 4 pares, entre 2 y 4 números bajos (1 a 20), sin tres seguidos y sin repetir una combinación que ya salió. Ninguna combinación tiene más probabilidad que otra.

        Conectar administración de GitHub

        Para guardar cambios, necesitas un token personal de GitHub con permiso Contents: Read and write únicamente para el repositorio xJuniorHopex/lotohope. El token se mantiene solo en la memoria de esta pestaña y no se guarda en el proyecto.

        Solo necesitas conectarlo para registrar, borrar o importar datos. Para consultar el historial no hace falta token.

        No compartas este token por el chat ni lo pegues en ningún archivo del repositorio. Al cerrar o recargar esta pestaña tendrás que conectarlo de nuevo.

        Respaldo

        Tus datos se guardan en el archivo data/resultados.json de GitHub. Descarga un respaldo cada cierto tiempo por si acaso.

        Importar

        Sirve el mismo formato de tu archivo: columnas #1 a #6, Mas, Super Mas, Dia, Mes y Año. Los sorteos se agregarán al historial de GitHub.

        Restablecer

        Borra TODOS los sorteos del archivo de GitHub. Esta acción no se puede deshacer; descarga primero un respaldo.
